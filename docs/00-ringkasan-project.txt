RINGKASAN PROJECT - JEJAK JAJAN
=================================================================
Update terakhir: 15 Oktober 2026

APA INI
Web arsip/ensiklopedia jajanan tradisional Indonesia berbasis
komunitas. Siapa pun bisa menambah jajanan: cerita asal-usul, resep,
langkah pembuatan, dan lokasi terakhir terlihat.

MASALAH
Jajanan tradisional makin sulit ditemukan: penjual makin sedikit dan
tidak punya penerus. Resep & ceritanya bisa hilang.

SOLUSI
Arsip online yang diisi bareng-bareng (crowdsourcing), dimoderasi admin.

PEMBEDA (vs Cookpad / TikTok / blog resep)
- Cerita & asal daerah, bukan resep saja
- Label kelangkaan hasil vote komunitas (umum s/d punah)
- Lokasi "Terakhir Terlihat di" + konfirmasi "Masih ada / Sudah tidak ada"
- Forum Jajanan: tanya resep/penjual, sejarah, tips, nostalgia
- Bukti komunitas "Sudah coba resep ini?" (Dicoba X orang, Y berhasil)

FITUR (daftar lengkap + status di docs/08-daftar-fitur.txt)
1. Beranda (marquee Hampir Punah, Baru Ditambahkan, footer lengkap),
   katalog + cari + filter
2. Halaman jajanan: cerita, resep, langkah, lokasi + mini map, Sudah coba
   resep ini?, simpan & koleksi, unduh PDF, mode masak
3. Kontribusi 7 langkah + kriteria katalog
4. Forum Jajanan (topik, balasan terbaik, laporkan)
5. Akun: profil + level kontributor, pengaturan profil & fitur, Pesan
6. Premium (mode demo, rencana Rp15.000/bulan) + iklan untuk akun gratis
7. Admin: moderasi + checklist, laporan, iklan, hapus jajanan, ganti foto
8. Kelas Bersama Penjual (segera hadir) + daftar minat
Belum: vote kelangkaan, Masih ada / Sudah tidak ada, komentar, edit
kontribusi, pembayaran asli.

ROLE
- User belum login : lihat semua konten
- User gratis      : kontribusi, simpan, forum, sudah coba resep (+ iklan)
- User Premium     : + bebas iklan, mode masak, PDF & koleksi tanpa batas
- Admin            : moderasi + otomatis Premium

MODEL BISNIS (detail di docs/06 revisi 2)
Arsip tetap gratis (tidak dikunci). Sumber pendapatan:
- Iklan / sponsor brand bahan kue & UMKM (slot sudah ada di web)
- Premium Rp15.000/bulan untuk kenyamanan (mode demo)
- Kelas bersama penjual (bagi hasil ke penjual)
- Nanti: afiliasi bahan, e-book, kerja sama pemda

TEKNOLOGI
Next.js 16 + Supabase (auth, database + RLS, storage foto) + Leaflet
(mini map). Deploy rencana ke Vercel (belum).
Desain dasar dari Figma "Jejak Jajan"; beberapa perubahan setelahnya
(sidebar kiri ala Cookpad, 3 font: Fraunces, Plus Jakarta Sans, Caveat,
dropdown daerah di kotak cari) belum diperbarui di Figma & docs/03.
